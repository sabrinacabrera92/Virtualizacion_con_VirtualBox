# Virtualizacion con VirtualBox
Este ejercicio te permitirá llevar la teoría a la práctica configurando tu primer entorno de pruebas controlado. Aprenderás a tomar decisiones sobre conectividad de red, una habilidad crítica para cualquier analista de seguridad.

Captura de pantalla de la sección de Red de VirtualBox:

<img width="896" height="571" alt="kali_red_modo_NAT" src="https://github.com/user-attachments/assets/b3d8553e-de2e-4a98-a0f0-f56e0e07156f" />

La VM de Kali Linux fue configurada con un adaptador de red en modo NAT para aislar la máquina de la red local física, actuando como un router invisible. Permite tener salida a Internet para instalar las actualizaciones, pero impide que dispositivos externos se conecten directamente a ella, protegiendo así a la computadora anfitriona de posibles fugas o ataques.
